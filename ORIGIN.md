# Project provenance

BlendLab evolved from Celaidon/Nap-in-a-boat:
https://github.com/Celaidon/Nap-in-a-boat

Upstream reference inspected: d65b6428928d064751fdf609769f4d428bd5ff1c.
Retain the upstream LICENSE and NOTICE with redistributed project code.

This repository imports the existing BlendLab working snapshot in small commits.
The import extends/adapts the frontend and includes local Ollama inference,
measured evaluation workflows, persisted benchmark/experiment JSON records,
and local Graphify context. These are import commits, not a reconstructed
historical development timeline. Commit timestamps reflect actual import times.

Model weights, generated graphs, local run history, secrets, and dependencies
are not included. Model and dataset terms remain separate from the code license.
